# Linear Regression Trainer

Eine interaktive Lern-App für Anfänger, um lineare Regression direkt im Browser zu verstehen und auszuprobieren.

## Live-Demo mit GitHub Pages

Dieses Projekt ist eine reine HTML/CSS/JavaScript-App und benötigt **keinen Server**. Nach dem Hochladen auf GitHub kann es direkt über **GitHub Pages** veröffentlicht werden.

### GitHub Pages aktivieren
1. Repository auf GitHub öffnen.
2. **Settings** → **Pages**.
3. Unter **Build and deployment** bei **Source**: `Deploy from a branch` wählen.
4. Branch `main` und Ordner `/ (root)` auswählen.
5. Speichern.
6. GitHub zeigt anschließend die öffentliche URL an.

## Funktionen
- Interaktive Datenregler
- Automatische lineare Regression im Browser
- Regressionsgerade und Residuen
- R², MAE und RMSE
- Vorhersage-Übung mit Punkten
- Anfänger-Quiz
- Beispieldaten-Tabelle
- Responsive Darstellung für Desktop und Mobilgeräte

## Dateien
- `index.html` – Seitenstruktur
- `styles.css` – Design
- `script.js` – Regression, Interaktion und Visualisierung

## Start lokal
Einfach `index.html` im Browser öffnen. Es ist keine Installation nötig.

## Lernziel
Die App zeigt anschaulich, dass lineare Regression einen kontinuierlichen Zahlenwert vorhersagt und wie Steigung, Achsenabschnitt, Streuung und Modellgüte zusammenhängen.
